Project name = StudioSpace Studio(Workspace Booking Platform)
Description

StudioSpace is designed to connect creative professionals with suitable workspaces. Users can browse available studios, explore workspace details, check amenities, read reviews, and book their preferred spaces.

The platform also provides studio owners with listing management features and users with a dedicated booking management system.

5 Key Features of StudioSpace

1. Studio Discovery: Browse, search, and filter creative workspaces with ratings, pricing, and detailed information.
2. Studio Management: Studio owners can create, update, and delete their workspace listings.
3. Workspace Booking: Users can book studios through an interactive booking modal.
4. Booking Management: Users can view reservations, track booking statuses, and cancel pending bookings.
5. Secure Authentication & Dashboard: Protected routes ensure users can manage only their own studio listings and bookings.


Run the Project Locally

1. Clone the repository: https://github.com/hemadry01/studiospace-client.git
2. Navigate to the project directory: cd your-repository
3. Install dependencies: npm install
4. Create a .env.local file and configure the required environment variables.
5. Start the development server: npm run dev
6. Open your browser and visit: http://localhost:3000
